# 🎨 Image Editor

A browser-based image editor built with HTML Canvas — featuring filters and presets.

## ✨ Features
- 🎛️ Filters — Brightness, Blur & more
- 🖼️ Ready-made Presets
- 🖥️ Built with HTML Canvas

## 🚀 Getting Started
```bash
npm install
npm run dev
```
